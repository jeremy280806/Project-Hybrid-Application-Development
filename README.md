# ServiConnect

Aplicasi mobile untuk menghubungkan penyedia jasa dengan klien, dibuat dengan Expo dan React Native.

## Menjalankan aplikasi

Pasang dependensi:

```bash
npm install
```

Jalankan development server:

```bash
npm start
```

Route utama aplikasi berada di `src/app/`, termasuk login, dashboard, feed, profil, dan pembuatan post. Route awal mengarahkan pengguna ke halaman login.
